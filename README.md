# MovieMatch Marrow v1 sandbox

A small, **fictional** movie-recommendation app used only as a disposable test
project for Marrow's original Pass 1 acceptance trial. It holds no real user,
customer, employee or financial data.

```
python -m pytest
```

- `PLAN.md` is the coding agent's v1 plan.
- `docs/architecture.md` and `docs/recommendation-flow.svg` are the meeting
  diagram.
- `main` is protected: changes land through pull requests with the
  `acceptance` check.
